
# Sistema de Renta de Videos - MongoDB

Este repositorio contiene la implementación en MongoDB para el caso práctico "Renta de videos".

## Estructura del Proyecto
* `seed.js`: Script para la creación de las colecciones e inserción de datos iniciales.
* `queries.js`: Script con consultas básicas y avanzadas (Aggregation Framework).

## Pasos para la Implementación

1. Asegúrate de tener instalado **MongoDB** y **mongosh** (MongoDB Shell).
2. Abre tu terminal y ejecuta el script de inicialización de datos:
   ```bash
   mongosh < seed.js
   ```
3. Ejecuta el script de consultas para verificar los resultados:
   ```bash
   mongosh < queries.js
   ```
